# GeoMuse 移动设备验收

日期：2026-07-29

## 自动化门禁

生产 Chromium 冒烟测试固定以下条件：

| 条件 | 设置 |
| --- | --- |
| 视口 | 390×844 |
| DPR | 2 |
| 输入 | `hasTouch` + DevTools 单点/双点触控 |
| 指针 | `(pointer: coarse)` |
| CPU | 4× slowdown |
| 动态偏好 | `prefers-reduced-motion: reduce` |

自动化必须验证：

1. 地球在 20 秒内进入“地球已就绪”；
2. 单指拖动改变相机并写入 `gm-view`；
3. 双指外扩提高缩放级别；
4. 触摸可打开图层面板并切换水系；
5. 触摸复位后清除默认镜头 URL；
6. 全流程没有控制台错误和未处理异常。

运行命令：

```bash
pnpm test:smoke:touch
```

## 自动化不能证明的内容

Chromium 仿真不能代替以下实体设备结论：

- 触摸屏采样率、手指遮挡和系统返回手势冲突；
- iOS Safari 的 WebKit 与 WebGL 驱动行为；
- Android 厂商 GPU 驱动和浏览器 WebView 差异；
- 持续操作后的温控降频、内存压力和标签页回收；
- 高 DPR 屏幕上的实际功耗和发热。

因此，在实体设备完成前，阶段 7D 的状态保持“部分完成”。

## 实体设备矩阵

至少覆盖以下三类设备。测试必须填写具体型号、系统、浏览器版本和实际结果。

| 类别 | 最低覆盖 | 状态 |
| --- | --- | --- |
| iPhone | 近三年机型，最新版 Safari | 待验收 |
| 主流 Android | 中端设备，最新版 Chrome | 待验收 |
| 低端 Android | 4–6 GB 内存或入门 GPU | 待验收 |

每台设备执行：

1. 无缓存首次打开首页，记录从导航到“地球已就绪”的时间；
2. 连续单指旋转 20 秒，确认没有明显卡死、错位或误点击；
3. 连续双指缩放 10 次，确认缩放方向稳定且不触发页面缩放；
4. 打开图层面板，切换三个图层组并复位视角；
5. 前后台切换一次，返回后继续操作；
6. 持续交互 3 分钟，记录发热、闪退、黑屏和上下文丢失；
7. 截图记录控制器、署名和安全区是否重叠。
